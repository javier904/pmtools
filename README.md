### Key Features
- **Agile Process Manager**: End-to-end guidance for PMs.
- **Kanban Board**: Advanced board with configurable WIP limits and per-column policy enforcement (temporal and activity-based).
- **Estimation Room**: Multimodal estimation (Planning Poker, T-Shirt, PERT).
- **Retrospectives**: Interactive sessions with AI-powered reporting.
- **Google Sheets Integration**: Seamless import/export of project data.
